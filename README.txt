edge-writer v2.8
================

v2.7 대비 변경점

1. 감수자 4종이 되었다 — 감 / 어사 / 도목수 / **배우(俳優) 신설**
   배우는 인물 입체성과 대사만 본다. 설정을 어기지 않았는데도 평면적인 지점을 찾는다.
   체크: 오프비트 유무와 유효성, 말버릇 과다, 손해 보는 선택, 주제 발화, 마찰, 화자 수,
         목소리 식별(말버릇 말고 다른 근거로 구별되는가), 침묵 처리.

2. 도목수 체크리스트에 10~14번 추가 — 호흡과 공간
   10. 장면 수 3~5, 최장/최단 2.5배 이상
   11. 미해결 컷 최소 1개 (없으면 중간 이상 심각도)
   12. 장면의 끝·시작 처리
   13. 서로 다른 공간 3개 이상 (5개 축 중 2개 이상 상이할 때만 '다름' 인정)
   14. 속도 배합 (장면 55~70 / 요약 15~30 / 정지 5~15)
   출력에 "호흡지적", "장면판정" 추가.

3. 감 체크리스트에 7번 추가 — 고증
   고증바이블의 금지 목록과 대조한다. '의도적으로 어기는 것' 표의 항목은 지적하지 않는다.
   출력에 "고증" 배열 추가.

4. 문서가 6종 → 8종
   craft(집필기법) · canon(고증바이블) 추가. 주입 대상:
     감      = 기획안·설정집·인물집·메타스키마·고증바이블
     어사    = 기획안·인물집
     도목수  = 로드맵·떡밥장부·기획안·집필기법
     배우    = 인물집·집필기법·기획안

설치
----
1. src/ 의 세 파일을 기존 프로젝트에 덮어쓴다 (App.jsx, api.js, lib/supabase.js).
2. Supabase SQL Editor에서 db/migrate-v2.8.sql 을 실행한다.
3. 앱 작품 설정에서 '집필기법'과 '고증바이블' 탭에 10_집필기법.md, 09_고증바이블.md 내용을 붙여 넣는다.
4. 작품 조건의 분량 표기를 5,500~6,500자로 맞춰 둔다.

주의
----
배우 감수는 인물집과 집필기법이 둘 다 채워져 있어야 제 기능을 한다.
집필기법이 비면 도목수 10~14번과 배우 전체가 판단 근거를 잃는다.
