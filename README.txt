edge-writer v2.7 — 확정 원고 수정 + 떡밥 상태 역행 방지

덮어쓸 파일 3개 (같은 경로에):
  src/App.jsx
  src/lib/supabase.js
  src/api.js        (v2.6과 같음 — 혹시 v2.6을 아직 안 올렸다면 같이 들어갑니다)

적용:
  git add -A && git commit -m "edge-writer v2.7" && git push
  → Vercel 자동 배포. DB(Supabase)는 손대지 않습니다.

바뀐 것
1) 확정된 회차를 불러오면
   - 「임시 저장」「원고 확정」 대신 「수정본 저장(확정 유지)」 하나만 보입니다.
   - 초록 띠 문구: "확정 원고 — 고친 뒤 「수정본 저장(확정 유지)」을 누르세요"
   - 저장해도 타임라인에 줄이 새로 붙지 않고, 기존 타임라인 요약도 지워지지 않습니다.
   - 이전 원고는 그대로 「이력」에 남습니다.

2) 옛 회차를 다시 저장해도
   - 더 뒤 회차가 바꿔 놓은 떡밥 상태는 건드리지 않습니다.
     (예: 8화를 다시 저장해도 15화에서 '회수'된 T027은 '회수' 그대로)
   - 저장 알림에 "N건은 뒤 회차 상태 유지"로 표시됩니다.
   - 같은 회차를 여러 번 저장해도 떡밥 이력이 중복으로 쌓이지 않습니다.
