# edge writer v1.2 — 설정 감수실

작품별 설정 문서(기획안·설정집·인물집)를 학습한 AI가 회차 원고를 교정하는 HANOK 감수 에이전트 PWA.

## 배포 (표준 절차)

1. GitHub 새 저장소 생성 → 이 폴더 전체 푸시
2. Vercel → Import Project → **Framework: Other 아님, Vite 자동 인식 (안 되면 Vite 선택)**
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. Vercel 환경변수 등록: `VITE_ANTHROPIC_API_KEY` = Anthropic API 키
4. Deploy

로컬 테스트: `npm install` → 루트에 `.env` 파일 생성(`VITE_ANTHROPIC_API_KEY=sk-ant-...`) → `npm run dev`

## 사용 흐름

1. **작품 서재**에서 작품 선택 (기본으로 『최약체 회귀병사』 요약본 시드 포함 — '문서 편집'에서 전문으로 교체 권장)
2. 새 작품은 **+ 작품 등록** → 3종 문서 붙여넣기
3. 회차 표기 + 원고 붙여넣기 → **감수 실행**
4. 리포트 확인 (설정 오류 / 인물 불일치 / 문체 / 떡밥 / 분량 / 훅)
5. 문제없으면 **타임라인 반영** — 이후 회차 감수 시 시계열 오류 검출 기준으로 사용됨

## 데이터

- 작품·타임라인은 브라우저 localStorage에 저장 (기기별 독립)
- 기기 이전/보호용으로 **백업 내보내기/불러오기** (JSON) 제공
- 갤럭시 탭 ↔ PC 간 동기화는 백업 파일로 수동 이전

## 구조

```
src/
  App.jsx         메인 UI (서재/감수/리포트/타임라인/모달)
  api.js          시스템 프롬프트 조립 + Claude API 호출 (claude-sonnet-4-6)
  defaultWork.js  시드 작품 데이터 (최약체 회귀병사 요약본)
  styles.css      원고지 × 빨간펜 교정 컨셉
```

## 감수 체크리스트 (api.js 시스템 프롬프트)

설정오류 / 인물불일치(타임라인 대조 포함) / 문체지적 / 떡밥체크 / 분량판정 / 훅판정 — JSON 구조화 출력.

## v1.1 변경사항 — 재감수 모드

- **재감수 실행 버튼**: 직전 감수 리포트가 있으면 활성화. 이전 리포트 전문을 프롬프트에 주입해 개정고를 대조 감수한다.
- **이전 지적 처리 판정**: 직전 지적 각각을 해결/부분해결/미해결로 판정해 리포트 최상단에 표시. 해결된 지적은 중복 제기하지 않도록 지시됨.
- **점수 변화 표시**: 직전 점수 대비 ▲/▼ 델타 표시.
- 직전 리포트는 작품별로 1건(`lastReview`) 저장되며 감수 실행 시마다 갱신된다.

권장 흐름: 감수 실행 → 수정 → **재감수 실행** → 해결 확인·점수 상승 → 타임라인 반영.

## v1.2 변경사항 — 4번째 문서: 로드맵

- **문서 구조 확장**: 기획안·설정집·인물집(안정 문서) + **로드맵(성장 문서)**. 작품 등록/편집 모달에 로드맵 입력칸 추가.
- **용도**: 회차별 중장기 계획(예: 11~20화, 21~30화 …)을 10화 단위로 이 필드에 계속 이어 붙여 관리한다. 기획안·설정집·인물집처럼 안정적으로 고정되는 문서가 아니라, 연재가 진행될수록 계속 늘어나는 문서다.
- **감수 반영**: 시스템 프롬프트에 로드맵 문서가 4번째 컨텍스트로 주입되며, 체크리스트에 **로드맵체크** 항목이 추가됐다. 로드맵에 지정된 시점보다 앞서 요소(예: "도핑은 48~50화 지정"인데 20화에서 언급)가 등장하면 조기노출로 판정한다. 리포트에도 "로드맵 체크" 섹션이 추가로 렌더링된다.
- **미기재 시 동작**: 로드맵 필드가 비어 있으면 감수는 이 항목을 건너뛰고 기획안의 대분류 구조(1부/2부/3부)만으로 판단한다 — 하위 호환 유지.

## 문서 관리 원칙 (권장)

- **기획안 / 설정집 / 인물집**: 거의 바뀌지 않는 설계 문서. CEO 판례도 여기 누적.
- **로드맵**: 10화 구간을 다 쓰면 다음 10화 로드맵을 이 필드 하단에 추가. 앞부분은 지우지 않고 누적 — 감수가 과거 아크의 조기노출 판정 기준도 계속 참조할 수 있도록.
- 로드맵이 너무 길어지면(예: 5부 이상 누적) 완결된 구간은 요약으로 압축하고, 다음 예정 구간만 상세하게 유지하는 것을 권장.
